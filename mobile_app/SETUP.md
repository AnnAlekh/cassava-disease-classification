# Инструкция по запуску Flutter MVP

## Шаг 1: Подготовка окружения

### Установите Flutter
```bash
# Проверьте, что Flutter установлен
flutter doctor
```

### Установите зависимости
```bash
cd mobile_app
flutter pub get
```

## Шаг 2: Запуск API сервера

### Вариант 1: Через Docker (рекомендуется)
```bash
# В корне проекта
docker-compose up -d

# Проверьте, что API работает
curl http://localhost:8000/health
```

### Вариант 2: Напрямую через Python
```bash
# В корне проекта
python app.py
```

API будет доступен на `http://localhost:8000`

## Шаг 3: Настройка URL API для мобильного приложения

### Для Android эмулятора:
По умолчанию используется `http://10.0.2.2:8000` - ничего менять не нужно.

### Для iOS симулятора или реального устройства:
1. Найдите IP адрес вашего компьютера:
   ```bash
   # Linux/Mac
   ip addr show | grep "inet "
   # или
   ifconfig | grep "inet "
   ```
2. Откройте файл `lib/services/api_service.dart`
3. Замените `baseUrl` на ваш IP:
   ```dart
   baseUrl = 'http://192.168.1.XXX:8000';
   ```

### Важно для реальных устройств:
- Убедитесь, что мобильное устройство и компьютер в одной Wi-Fi сети
- На компьютере разрешите подключения на порту 8000 в firewall

## Шаг 4: Запуск приложения

### Android
```bash
# Запустите Android эмулятор или подключите устройство
flutter run
```

### iOS (только на Mac)
```bash
# Запустите iOS симулятор или подключите устройство
flutter run
```

## Проверка работы

1. Откройте приложение
2. Нажмите "Начать сканирование"
3. Выберите фото из галереи (или сделайте фото)
4. Дождитесь результата диагностики
5. Проверьте историю сканирований

## Устранение проблем

### Ошибка "API недоступен"
- Проверьте, что API сервер запущен: `curl http://localhost:8000/health`
- Проверьте URL в `lib/services/api_service.dart`
- Для реальных устройств проверьте, что IP адрес правильный

### Ошибка камеры/галереи
- Проверьте разрешения в AndroidManifest.xml (Android)
- Проверьте разрешения в Info.plist (iOS)
- Для iOS убедитесь, что симулятор поддерживает камеру

### Ошибка подключения к базе данных
- Убедитесь, что все зависимости установлены: `flutter pub get`
- Проверьте версию Flutter: `flutter --version` (нужна >= 3.0.0)
