# 📊 Датасеты для определения заболеваний растений в Красноярском крае

Этот документ содержит информацию о доступных датасетах, которые можно использовать для разработки системы определения заболеваний растений, адаптированной для Красноярского края.

## 🌾 Основные культуры Красноярского края

### Зерновые культуры
- **Пшеница** - основная зерновая культура
- **Ячмень** - яровая и озимая
- **Овес** - кормовая культура
- **Рожь** - озимая культура

### Овощные культуры
- **Картофель** - одна из основных культур
- **Капуста** - белокочанная
- **Морковь** - корнеплодная культура
- **Свекла** - кормовая и столовая
- **Лук** - репчатый и зеленый
- **Томаты** - тепличные культуры

### Ягодные культуры
- **Клубника/Земляника**
- **Смородина** (черная, красная)
- **Крыжовник**

## 🔬 Рекомендуемые датасеты

### 1. PlantVillage Dataset
**Описание**: Классический и самый популярный датасет для классификации заболеваний растений.
- **Размер**: ~54,000 изображений
- **Культуры**: 38 видов растений (включая помидоры, картофель, пшеницу, кукурузу)
- **Классы**: Здоровые и различные заболевания
- **Ссылка**: https://github.com/spMohanty/PlantVillage-Dataset
- **Альтернатива**: https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset

**Применимость для Красноярского края**: ✅ **Высокая**
- Включает пшеницу, картофель, томаты
- Можно адаптировать под региональные условия

**Преимущества**:
- Большой объем данных
- Хорошая аннотация
- Используется во многих исследованиях

**Недостатки**:
- Изображения на белом фоне (не всегда соответствует реальным условиям)
- Не все культуры, выращиваемые в Красноярском крае

---

### 2. PlantDoc Dataset
**Описание**: Датасет с изображениями растений в естественных условиях.
- **Размер**: 2,598 изображений
- **Культуры**: 13 видов растений
- **Классы**: 17 классов заболеваний
- **Ссылка**: https://github.com/pratikkayal/PlantDoc-Dataset
- **Статья**: https://arxiv.org/abs/1911.10317

**Применимость для Красноярского края**: ✅ **Средняя-Высокая**
- Изображения в естественных условиях
- Включает некоторые культуры региона

**Преимущества**:
- Реалистичные условия съемки
- Лучшая обобщающая способность модели

**Недостатки**:
- Меньший размер датасета
- Ограниченное количество культур

---

### 3. PlantSeg Dataset
**Описание**: Крупномасштабный датасет с сегментационными масками.
- **Размер**: 11,400 изображений с болезнями + 8,000 здоровых
- **Особенность**: Сегментация заболеваний на листьях
- **Ссылка**: https://arxiv.org/abs/2409.04038

**Применимость для Красноярского края**: ✅ **Средняя**
- Большой объем данных
- Сегментация позволяет точнее локализовать заболевание

**Преимущества**:
- Детальная аннотация (маски сегментации)
- Большой размер датасета
- Изображения в естественных условиях

**Недостатки**:
- Требует адаптации под культуры региона
- Сложнее в использовании (сегментация vs классификация)

---

### 4. Plant Pathology Challenge (Kaggle)
**Описание**: Конкурс Kaggle с различными датасетами по заболеваниям растений.

#### 4.1. Plant Pathology 2020 - FGVC7
- **Фокус**: Яблони (но методы применимы)
- **Ссылка**: https://www.kaggle.com/c/plant-pathology-2020-fgvc7

#### 4.2. Plant Pathology 2021 - FGVC8
- **Фокус**: Пшеница
- **Ссылка**: https://www.kaggle.com/c/plant-pathology-2021-fgvc8
- **Применимость**: ✅✅✅ **Очень высокая** (пшеница - основная культура Красноярского края)

#### 4.3. Plant Pathology 2021 - Few Shot Learning
- **Фокус**: Немногошотовое обучение
- **Ссылка**: https://www.kaggle.com/c/plant-pathology-2021-fgvc8-classification

**Преимущества**:
- Актуальные данные
- Хорошая аннотация
- Реальные условия съемки

---

### 5. DeepWeeds Dataset
**Описание**: Датасет для классификации сорняков (Австралия).
- **Размер**: 17,509 изображений
- **Классы**: 8 видов сорняков + фоновый класс
- **Ссылка**: https://github.com/AlexOlsen/DeepWeeds
- **Применимость**: ⚠️ **Ограниченная**
  - Полезен для различения культурных растений и сорняков
  - Не применим напрямую к заболеваниям

---

### 6. Agricultural Crop Disease Dataset (Kaggle)
**Описание**: Различные датасеты по заболеваниям сельскохозяйственных культур.
- **Примеры**:
  - Corn Disease Dataset
  - Wheat Disease Dataset
  - Potato Disease Dataset
- **Поиск**: https://www.kaggle.com/datasets?search=plant+disease

---

### 7. Tomato Leaf Disease Dataset
**Описание**: Специализированный датасет для заболеваний томатов.
- **Применимость**: ✅ **Высокая** (томаты выращиваются в теплицах)
- **Ссылки**:
  - https://www.kaggle.com/datasets/kaustubhb999/tomatoleaf
  - Часть PlantVillage содержит данные по томатам

---

### 8. Potato Disease Dataset
**Описание**: Специализированный датасет для заболеваний картофеля.
- **Применимость**: ✅✅✅ **Очень высокая** (картофель - основная культура)
- **Ссылки**:
  - https://www.kaggle.com/datasets/potato-disease-dataset
  - Входит в PlantVillage

## 📥 Рекомендуемый подход

### Этап 1: Базовое обучение (Transfer Learning)
1. Использовать **PlantVillage Dataset** для общего обучения
2. Особое внимание к:
   - Пшенице (Plant Pathology 2021 - FGVC8)
   - Картофелю (PlantVillage)
   - Томатам (PlantVillage)

### Этап 2: Адаптация к региональным условиям
1. Собрать локальные данные в Красноярском крае
2. Использовать **fine-tuning** на региональных данных
3. Применить методы **domain adaptation**

### Этап 3: Сбор локального датасета
1. Сотрудничество с КрасНИИСХ
2. Сбор данных с фермерских хозяйств
3. Использование данных от Россельхозцентра
